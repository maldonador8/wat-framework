# Workflow: Cold Outreach Generator

## Objective
Generate hyper-personalized cold emails that book meetings and close deals. Napoleon Hill's #1 lesson: "The ability to sell is the most important skill an entrepreneur can develop." This tool makes you a world-class closer at scale.

## The Framework
Every email uses three proven systems:
1. **AIDA** — Attention → Interest → Desire → Action
2. **Napoleon Hill's Burning Desire** — Make the cost of NOT acting vivid
3. **Rich Dad positioning** — Sell outcomes, not features. Assets, not expenses.

## When to Use
- Prospecting for Claude Code consulting clients (MITech LLC)
- Church/ministry partnerships for Bible with AI
- Any B2B or B2C sales situation
- Follow-up sequences

## Required Inputs
- `ANTHROPIC_API_KEY` in environment
- `anthropic` Python package: `pip install anthropic`

## Tool
```
tools/cold_outreach.py
```

## Usage Examples

### Claude Code Consulting (MITech LLC)
```bash
python tools/cold_outreach.py \
  --name "Sarah Chen" \
  --company "TechStart Inc" \
  --role "CTO" \
  --pain "Dev team spending months building features Claude Code could do in hours" \
  --product "Claude Code consulting — MITech LLC" \
  --offer "free 1-hour AI workflow audit"
```

### Church Partnerships for Bible with AI
```bash
python tools/cold_outreach.py \
  --name "Pastor James Wilson" \
  --company "Cornerstone Baptist Church" \
  --role "Senior Pastor" \
  --pain "Sermon prep taking 10+ hours per week, congregation wants more digital engagement" \

```

### Batch Processing
Create a CSV file `prospects.csv`:
```
name,company,role,pain,offer
John Smith,First Baptist,Pastor,Sermon prep and digital outreach,free 30-day trial
Maria Garcia,Grace Community,Youth Pastor,Keeping youth engaged with scripture,free 30-day trial
```

Then run:
```bash
python tools/cold_outreach.py \
  --csv prospects.csv \
  --product "Bible with AI (biblewithai.com)" \
  --offer "free 30-day church account"
```

## Expected Output
- Subject line (under 45 chars, no spam)
- Email body (100-150 words — respects prospect's time)
- Signature block
- P.S. urgency/social proof line
- Follow-up email (for 3-day no-reply follow-up)
- Saved to `.tmp/outreach_YYYY-MM-DD_name.md`

## The Follow-Up System (Napoleon Hill: Persistence)
- Day 0: Send cold email
- Day 3: Follow-up (generated by tool) — add new value
- Day 7: Final follow-up — "closing the loop"
- Day 30: Re-engage with new angle or case study

## What NOT to Do
- Don't use generic openers ("I hope this email finds you well")
- Don't talk about features — talk about outcomes
- Don't send more than 3 follow-ups
- Don't CC anyone on the first touch
- Don't attach anything — put the link in the body
